# 🚀 Legacy Project Revived & Modernized with Python

A legacy MERN stack application successfully rescued and modernized by replacing the inactive Node.js backend with a high-performance Python ecosystem.

## 🛠️ Tech Stack Transformation

* **Backend:** Migrated from **Node.js (Express)** ➡️ **Python (FastAPI)** for asynchronous speed and native data validation.
* **Database:** Upgraded from a defunct **MongoDB** instance ➡️ Serverless **PostgreSQL (Neon.tech)** using SQLModel ORM.
* **Frontend Preservation:** Maintained the original **React / Redux** client by seamlessly emulating legacy NoSQL data structures (like dynamic string IDs) on a relational SQL database.
* **Deployment:** Fully containerized using a multi-stage **Docker** build and deployed live on **Render**.

## ⚡ Key Features Implemented

* **Strict Input Validation:** Powered by Pydantic to block malicious characters dynamically.
* **Auto-generated Documentation:** Interactive Swagger UI available at `/docs`.
* **Unified Architecture:** Python serves both the secure REST API and the compiled React SPA from a single container.
